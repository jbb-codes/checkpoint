# Fixed three-tag finding classification: auto-fix, no-op, ask-user

Every finding a stage surfaces needs a machine-decidable answer to "does this need a human?" so mechanical issues don't interrupt flow but real product decisions never get silently approved. We fixed the classification to exactly three tags — `auto-fix`, `no-op`, `ask-user` — with unchanging names, rather than a severity-only scheme or backend-defined custom actions. `ask-user` findings must always reach the human unless the user has given standing consent to drive unattended; an agent driver may resolve `auto-fix`/`no-op` on its own judgment. A more granular or backend-extensible scheme was rejected because it would make the "will this block me" question backend-dependent instead of a protocol-level guarantee.
